# E-Commerce Shipping Delay Prediction

## Overview
This project focuses on predicting e-commerce shipping delays using machine learning. The primary goal is to analyze historical delivery patterns, clean the data, and build baseline classification models to identify potential logistical bottlenecks.

## Current Progress
* **Exploratory Data Analysis (EDA):** Analyzed the shipping dataset to extract actionable insights and understand the distribution of variables.
* **Data Preprocessing:** Handled missing values, formatted features, and prepared the dataset for model training using standard numerical techniques.
* **Baseline Modeling:** Built and tested initial machine learning classification models to establish a baseline accuracy score. 

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

## Next Steps
* Upgrading the architecture to implement an ensemble model (Random Forest) to improve prediction accuracy and handle complex non-linear relationships.
